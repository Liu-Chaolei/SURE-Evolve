# Variable Identification Agent User Prompt

请分析以下调查数据变量，判断其角色、类型、无回答值和测量处理建议。

## 任务

对以下每个变量，你需要：
1. 理解变量的含义和测量对象
2. 判断变量类型（数据类型）
3. 分配候选角色（研究用途）
4. 识别无回答值编码（拒答、不知道、不适用、跳题）
5. 建议测量处理方式（作为 X 和 Y 分别建议）
6. 识别与其他变量的机械关系

## 输入数据

变量列表（JSON 格式）：
{variable_list}

## 重要约束

1. **不得根据显著性或变量间相关性分配角色**
2. **必须逐个标注所有变量，不得遗漏**
3. **语义信心（semantic_confidence）仅表示判断把握，不进入统计评分**
4. **不确定的处理建议必须选择 none**
5. **机械关系可以指向 prior_variables 或当前变量列表中的任意其他变量**

## 输出要求

为每个变量返回一个完整的 JSON 对象，包含所有必填字段。确保：
- roles 数组至少包含一个角色
- nonresponse_values 只包含明确无回答含义的编码
- mechanical_links 数组可以为空（没有机械关系时）
- 所有布尔字段必须是真正的 JSON 布尔值（true/false）

请按照系统提示词中定义的 JSON Schema 输出完整结果。
