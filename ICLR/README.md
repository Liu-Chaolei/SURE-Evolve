# SURE-Evolve 中文稿（ICLR 2027 / Overleaf）

将本目录中的全部文件上传到 Overleaf 项目根目录。主文件 `sure_evolve_zh.tex` 使用 XeLaTeX、`ctex` 和 `xeCJK` 处理中文；请在 Overleaf 菜单中选择 XeLaTeX。参考文献使用同目录下的 `sure_evolve_refs.bib` 和 `iclr2027_conference.bst`。

当前稿件保留蓝色的实验结果待填项，并使用匿名审稿格式。中文字体使用 Overleaf TeX Live 可用的 Noto Serif CJK SC/Noto Sans CJK SC，不依赖本地 Windows 字体。
